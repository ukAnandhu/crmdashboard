# Mini CRM Dashboard

A responsive Mini CRM (Customer Relationship Management) Dashboard built using React.js and Tailwind CSS. This application helps manage customer information through a simple and user-friendly interface with complete CRUD functionality and form validation.

## 🚀 Features

- **Dashboard Overview** – Clean and responsive dashboard layout.
- **Customer Management** – Add, view, edit, and delete customer details.
- **Add Customer Modal** – User-friendly modal for adding new customers.
- **Form Validation** – Integrated React Hook Form and Zod for form validation.
- **Email Validation** – Prevents duplicate email addresses, including case-insensitive duplicates.
- **Responsive Design** – Works across desktop, tablet, and mobile devices.
- **Tailwind CSS** – Modern styling with reusable UI components.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Vite

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/ukAnandhu/crmdashboard.git
```

### 2. Navigate to the project directory

```bash
cd mini-crm
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
